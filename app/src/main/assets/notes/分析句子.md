#### 句子主干: 一个句子最核心的信息
```sql
1, 看到一个复杂的句子,不是先翻译第一个单词, 而是先看: 谁在做? 也就是主语
The system generates the file every day. 主语 : The system

2, 找到主语后, 找第二个,也就是主语做了什么?
The system generates the file. 做了啥: generate 生成

3, 找到动作后, 看下动作的对象是什么? 也就是做了什么东西?
The system generates the file. 动作的对象: 文件

The system → 谁  
generates → 做什么  
the file → 对什么做
```
#### 五大基本句型
```sql
1, 主语 + 谓语 (S+V), 核心: 谁/什么 + 做了什么
The system crashed. 系统奔溃了

这种句型不需要宾语, 因为主语+谓语就能够表达完整的意思了, 总不能说系统奔溃了什么东西吧

2, 主语 + 谓语 + 宾语 (S+V+O), 谁 + 做了什么 + 对什么做
The system generates the file.

- The system → S
- generates → V
- the file → O

3, 主语 + 谓语 + 补语 (S+V+C),也叫做主系表, 补语:说明主语的特征, 状态或者身份, 谓语: 这个句型里面的谓语都叫系动词
3.1, 状态系动词(Be动词: am, is, are, was, were),表示主语处于什么状态,身份
	He is an engineer. 说明主语身份 - 工程师
	They are at home 说明主语位置 - 家里
	I am angry. 说明主语状态 - 生气中
3.2, 感官系动词(look, smell, taste, sound, feel),表示凭视觉、嗅觉、味觉、听觉、触觉感受到的状态
	The flower smells sweet. 花闻上去甜
	You look tired today. 你看上去疲惫
3.3 变化, 持续系动词(become, get, turn, keep, stay, seem),主语从一种状态改变为另一种状态，或保持某种状态
	The weather is getting cold. 天气变得更冷了
	Leaves turn yellow in autumn.树叶在秋天变黄了

4, 主语 + 谓语 + 间接宾语 + 直接宾语 (S+V+O+O), 谁 + 做了什么 + 给谁 + 什么东西
The system sent the user an email.

The system → S  
sent → V  
the user → O  
an email → O

5, 主语 + 谓语 + 宾语 + 宾语补语 (S + V + O + C),宾语补语: 补充说明宾语的状态/动作/身份, 谓语动词做完动作后，宾语的意思还不完整，必须加一个“补语”来补充说明宾语“怎么样了”或“干了什么
5.1 名字做宾语补语 - 补充宾语的“身份/名称”
	We named the puppy Lucky. 我们叫这个小狗Lucky
5.2 形容词作补语 - 补充宾语的“状态/特征”
	The bad news made him sad.
	Keep the door open.
5.3 动词不定式（to do）作补语 - 说明宾语“要去做的动作”
	My mother asked me to clean the room. （我妈妈让我去打扫房间。）
5.4 分词（doing / done）作补语（说明宾语“正在做”或“被做”）
	I saw her dancing in the room.（我看见她正在房间里跳舞。）
	I had my computer repaired yesterday. （我昨天把电脑拿去修了/ 我让我的电脑被修好了）
		** 不是过去完成时, 这里的have类似于让..., 这里的电脑是 : 被修好
```
#### 6种主要成分: 主语、谓语、宾语、定语、状语、补语 (前三个骨架, 后三个修饰)
```sql
句子骨架成分:
主语: 动作的发起者,执行者
谓语: 说明主语做什么 / 是什么 / 怎么样
宾语: 动作的承受者

句子修饰成分
定语: 修饰名词/代词 (不一定是主语和谓语, 只要句子内名词都能修饰), 说明什么样的人 / 物
	The new system generates the file. 修饰主语: the system
	The system generates the new file. 修饰宾语: file
	He is a good developer. 修饰表语里面的名词: developer
状语: 动词、形容词、副词或整个句子, 说明动作发生的:时间、地点、方式、原因、程度等（“怎么地”做）
	时间状语(什么时候, 多久, 多久一次):
		I checked the file yesterday. 什么时候
		We generate the file every day. 多久一次
	地点状语 (在哪里, 到哪里, 从哪里):
		I work in Bangkok. 在哪里
		We moved the data to the new database. 到哪里
	方式状语 (怎么做):
		The system processes the data automatically. 自动地做
		He answered the question carefully. 小心地回答
	程度状语 (有多, 到什么程度): 
		He works very hard. 非常努力地
	条件状语 (什么情况下):
		If the account is dormant, the system will exclude it. 如果账户休眠
	原因状语 (为什么?):
		I stayed home because I was sick. 因为生病.
	目的状语 (为什么目的?):
		I went to the bank to open an account. 为了开户
补语: 
	1, 用在主语+谓语+补语(主系表)结构, 这里的补语也叫表语,具体见“五大基础句型的第三种”
	2, 用在主语+谓语+宾语+宾语补足语结构, 具体见“五大基础句型的第五种”
```

#### 非谓语动词: 位了让一个句子表达额外的动作,不需要把这些动作变成额外的谓语
```sql
核心: 英语里面, 一个句子只能有一个核心谓语
1, 不定式做非谓语动词: to + 动词原形
常见用法: 
	目的状语: I came here to learn English. 我来这儿为了学习英语
	定语: I have a report to finish. 我有一个需要完成的报表,(后置定语)
	宾语: I want to learn English.我想学习英语
	
2, 现在分词/ 动名词做非谓语动词: doing
	主语: Learning English is difficult.
	宾语: I enjoy learning English.
	定语: The man standing outside is my manager.
	时间状语: Checking the file, I found an error.
	
	doing作名词, 那么就是动名词: 
		Learning English is difficult.
		I enjoy learning English.
	doing作形容词/副词/状语, 那么就是现在分词: 
		The man standing outside is my manager.
		The system processing the data is very slow.
		
3, 过去分词做非谓语动词
	The file generated yesterday is incorrect. 昨天生成的那个文件是错误的
```
#### 从句: 当单个单词不够表达时, 就会把一个完整句子当做一个大词塞进主句里, 被塞进去的子句叫从句, 完整的大句子叫主句
```sql
关键: 非谓语其实就是从句的瘦身版本
- _从句版_：_The girl **who is standing there** is my friend._
- _非谓语版_：_The girl **standing there** is my friend._（直接省掉 _who is_）
  
1, 名词性从句, 整个句子充当名词
	I know that the system has a problem.
2, 定语从句, 整个句子修饰名词
	The file that contains all accounts is incorrect.
3, 状语从句, 整个句子修饰动词/修饰句子
	When the job finishes, we will generate the report.
```
