#### 一般现在时 : 表示经常发生, 习惯或者客观事实,
```sql
结构: 主语 + 动词
否定句 : do not / does not + 动词原形
疑问句: Do / Does + 主语 + 动词原形?

I work here 我在这工作
she does not work here 她不在这里工作
Do you understand ?  你理解了吗?
```
#### 一般过去时: 表示过去发生并且已经结束
```sql
结构 : 主语 + 动词过去式
否定句 : did not + 动词原形
疑问句 : Did + 主语 + 动词原形?

I worked here yesterday 我昨天在这上班
```
#### 一般将来时 : 将来会发生的事
```sql
结构 : 主语 + will + 动词原形
否定句: will not + 动词原形
疑问句: Will + 主语 + 动词原形 ?

I will work here tomorrow 我明天在上班
```
#### 现在进行时: 现在正在发生的事 (我现在正在工作)
```sql
结构: 主语 + am/is/are + 动词ing
否定句: am/is/are not + 动词ing
疑问句: Am/Is/Are + 主语 + 动词ing?

I am working now 我现在正在上班
I am not working now 我现在没有上班
Are you working now? 你现在在上班吗?
```
#### 过去进行时: 过去某个时间点, 正在发生的事 (我当时正在工作)
```sql
结构: was / were + 动词ing

I was working at 8 PM yesterday 昨晚8点的时候, 我正在工作
```
#### 将来进行时: 将来的某个时间点, 正在做啥 (我到时候正在工作)
```sql
结构: will be + 动词ing

I will be working at 8 PM tonight 今晚8点我会正在工作
```
完成时的概念: 在某个时间点之前, 动作就已经完成了
#### 现在完成时:  在说话的这个时间点, 已经做了的事
```sql
结构: 主语 + have / has + 动词过去分词

I hava finished the work 我已经完成了工作 (时间点是: 说话的现在)
```
#### 过去完成时: 在过去某个时间点之前就已经做了的事, 过去的过去
```sql
结构: 主语 + had + 过去分词

图示:
完成报告              他来了
   ↓                    ↓
---●--------------------●---
   had finished          came

I had finished the report before he came 我在他来之前就已经完成了报告 (时间点: 他来的时候, 所以他来用了: 一般过去时, 然后完成报告比他来发生得更早)
```
#### 将来完成时: 未来某个时间点之前, 某个事情要已经完成
```sql
结构: 主语 + will have + 动词过去分词

I will have finished the report by tomorrow 截止到明天, 我将已经完成报告 (当下是没有做 或者做完的.)
```
完成进行时 = 到某个时间点为止，已经持续做某事一段时间, 
- **完成** → 从过去一直延续到某个时间点
- **进行** → 强调这个过程/持续时间
#### 现在完成进行时: 在现在这个时间点, 已经持续做的事
```sql
结构: 主语 + have/has been + 动词-ing
常用单词: 
since: 从什么时间开始 (给了开始时间点,从开始时间点到现在推算出: 持续时间)
for : 持续时间 (给了持续时间, 开始时间点需要倒推)

I have been working for 3 hours 我已经工作了三个小时 (时间点: 现在说话时, 持续时间: 3个小时, 我从3小时前开始工作，一直持续到现在)

时间轴:
3小时前                         现在
  ↓                              ↓
  ●══════════════════════════════●
          have been working
```
#### 过去完成进行时: 在过去某个时间之前，已经持续做某事一段时间。
```sql
结构: 主语 + had been + 动词-ing

I had been working for 3 hours when he called me 当他打电话给我的时候, 我就已经工作了3个小时 (时间点: 他打电话给我的时候, 打电话用一般过去时)
```
#### 将来完成进行时: 到了未来某个时间前，将已经持续做某事一段时间。
```sql
结构: 主语 + will have been + 动词-ing

By next month, I will have been working here for 2 years. 到下个月为止, 我将已经工作了2年

```
